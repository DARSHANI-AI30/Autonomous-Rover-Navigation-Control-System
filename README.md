# 🚀 AstraEdge – Energy-Efficient AI Rover Navigation
https://astraedge-vision.lovable.app

## 📌 Overview

AstraEdge is an intelligent rover navigation system designed to optimize **energy consumption** rather than just shortest distance. It simulates how autonomous rovers can make smarter navigation decisions in challenging environments such as Mars.

---

## ❗ Problem Statement

Traditional pathfinding algorithms like A* focus on the shortest path but ignore terrain-based energy costs.
In real-world planetary exploration, this can lead to:

* High battery consumption
* Inefficient navigation routes
* Increased risk of mission failure

---

## 💡 Proposed Solution

AstraEdge introduces an **energy-aware navigation approach** that:

* Assigns energy cost to different terrain types (flat, sand, obstacles)
* Selects routes based on minimum energy consumption
* Simulates intelligent decision-making for rover movement

---

## ⚙️ Key Features

* 🔍 A* vs Energy-Aware path comparison

## ▶️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/DARSHANI-AI30/astraedge-vision.git
   ```

2. Navigate to the project folder:

   ```bash
   cd astraedge-vision
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Run the project:

   ```bash
   npm run dev
   ```

5. Open in browser:

   ```
   http://localhost:5173
   ```
